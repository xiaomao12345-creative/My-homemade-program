# 我的自制程序
这里包含着我的许多自制程序，大家可以下载使用，但是下载前可不可以给一个星？

## 类别
我的自制程序分为许多类
- 1.工具类
  有许多实用的工具，可能是帮助你下载的（有些要登录），但是不想登录的
- 2.恶搞程序类
  如果你是一个喜欢恶搞程序的人，你可以尝试下载并使用，建议在虚拟机上使用，有些会对电脑有害
- 3.开发类
  如果你是一个程序员，但是不想使用英文开发，你可以使用汉化的（比如我的作品《中文命令提示符》之类的，看我别的仓库）
- 4.其他类
  这里上传着其他类型的程序，有需要自取即可

- 2.该产品请不要擅自分发
